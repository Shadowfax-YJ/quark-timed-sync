夸克网盘定时同步 1.0.0

运行
Windows：完整解压 ZIP，双击 夸克网盘定时同步.exe。
Mac：完整解压 ZIP，打开 夸克网盘定时同步.app。Apple 芯片，macOS 12 或更新。
无需安装 Python、Node、Docker、OpenList 或 rclone。下载组件已包含在包内。

首次使用
1. 点击“登录夸克网盘”，使用手机夸克扫码并确认登录。
2. 点击“添加订阅”，选择自己的网盘目录，或粘贴夸克分享链接并选择其中的目录。
3. 选择本地目标文件夹，设置检查间隔（默认 60 分钟，最短 5 分钟），创建订阅。
所选云端目录里面的内容直接保存到目标目录，不会额外套一层同名目录。
例如：选择云端 archive，再选择本地 D:\Downloads\archive。
别人分享的内容会先转存到你自己的网盘 /Archive 订阅/订阅-编号，再下载到本地。
此过程需要自己的夸克账号和足够的网盘空间；程序不会自动删除转存文件。
如果链接属于当前登录账号，程序会识别为自己的分享，直接下载原文件，不会重复转存。

下载规则
定时检查云端目录；保留目录结构，只下载本地没有的文件。
同名文件无论大小、时间是否变化，均跳过；不覆盖，不删除，不生成旧版本。
第一次订阅也会下载尚未存在于本地的历史文件。
部分下载由内置 rclone 管理，下次运行重试；完整文件完成后才发布到目标文件名。
非法文件名、仅大小写不同的重名路径、符号链接路径会停止该次任务并显示错误。

暂停和退出
“暂停全部”停止当前下载及后续自动检查，暂停状态重启后仍然保留。
单个订阅也可以暂停；“立即检查”允许在暂停期间手动检查一次，不会恢复自动检查。
关闭窗口会隐藏到 Windows 系统托盘或 Mac 菜单栏。
托盘菜单或应用中的“退出并停止下载”会结束下载器及内置网盘服务。
只有应用运行期间才会检查；退出后没有独立计划任务继续下载。
开机启动默认关闭，可在左下角开启。移动便携程序的位置后，请重新设置此选项。

数据位置
更名后继续使用原数据目录，已有登录和订阅配置会沿用。
Windows：%APPDATA%\Archive Subscriptions
Mac：~/Library/Application Support/Archive Subscriptions
便携表示免安装、无外部运行依赖。配置和日志仍保存在当前系统用户的数据目录。
夸克登录凭据由操作系统加密，不能拿到另一台机器复用；合作者需登录自己的账号。
内部网盘服务只监听 127.0.0.1，使用每次启动随机生成的密码和端口。
分发包内不包含任何个人账号、网盘链接、下载目录或已下载文件。

macOS 首次打开
当前包采用本地签名验证，未使用 Apple Developer ID 公证。
如果 macOS 阻止运行：尝试右键应用选择“打开”，或在系统设置的“隐私与安全性”中选择“仍要打开”。
若系统或公司策略不允许未公证应用，需要 Developer ID 签名版本；不能保证所有系统均能免提示启动。
不需要关闭 Gatekeeper、杀毒软件或任何全局系统防护。

常见问题
无法连接或登录过期：重新扫码后再检查。
分享失效、提取码错误或容量不足：修正来源/空间问题；现有本地文件不受影响。
订阅来源或保存目录需要变化：移除订阅并重新添加。移除只移除规则，不删除本地或网盘文件。
夸克可能调整接口和下载限制；第三方软件无法保证接口永久不变或超出账号权益的下载速度。
此版本为轮询下载，不是夸克服务器主动推送。
