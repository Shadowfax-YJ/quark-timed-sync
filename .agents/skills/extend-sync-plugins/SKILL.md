# 同步插件维护

先读 [本仓库插件契约](../../../docs/plugins.md)，核对 `src/plugins.cjs`、`src/engine.cjs` 和 `src/model.cjs`。用本地合成文件/进程测试，保留基础追加下载的回归覆盖。

宿主管理追加下载、通用插件执行和状态，业务数据格式、内容验证和分析逻辑放在外部插件。默认用户流程保持 GUI 登录与订阅，插件按需启用。保持订阅未启用插件时的既有行为，插件版本与宿主协议范围分别声明。宿主仅解释协议中的通用状态和进度，插件专有结果原样保存。

变更必须处理零新增、部分失败、取消、文件落地后退出与重启补投。计划文件数不是实际完成证明；插件验证与下载分别呈现。相同输入重复处理不重复产生业务结果。

默认引擎跳过已有同名文件。用户明确启用修订同步时，按 [文件修订协议](../../../docs/file-revisions.md) 校验 SHA256、保留原件后替换；此通用能力属于宿主。维护历史归档、哈希更新或修订发布时必须读取该协议，并通过文档中的维护接口调用传输能力。验证默认只读、显式写入、路径限制和失败关闭服务；业务发布规则由调用方提供。采用追加下载的数据发布使用新增不可变路径。

宿主协议改变时更新本仓库文档和通用测试，再检查已有插件配置及响应的兼容性。公共文档面向所有夸克用户，示例使用合成文件和通用字段；具体业务项目的安装、升级、部署与协作说明由外部插件仓库维护。
