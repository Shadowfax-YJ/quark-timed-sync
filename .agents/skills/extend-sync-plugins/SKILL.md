# 同步插件维护

先读 [本仓库插件契约](../../../docs/plugins.md)，核对 `src/plugins.cjs`、`src/engine.cjs` 和 `src/model.cjs`。用本地合成文件/进程测试，保留基础追加下载的回归覆盖。

宿主管理追加下载、通用插件执行和状态，业务 schema、快照验证和分析逻辑放在外部插件。默认用户流程保持 GUI 登录与订阅，领域插件为按需扩展，分析读取器已能校验的数据不要求额外同步运行时。保持订阅未启用插件时的既有行为，插件版本与宿主协议范围分别声明。

变更必须处理零新增、部分失败、取消、文件落地后退出与重启补投。计划文件数不是实际完成证明；插件验证与下载分别呈现。相同输入重复处理不重复产生业务结果。

当前引擎跳过所有已有同名文件。业务发布使用新增的不可变路径，不能依赖覆盖 `latest.json`。本地损坏文件要显式诊断并通过受限修复流程恢复，不能用插件静默改掉“只追加”的用户约定。

宿主协议改变时更新本仓库文档和通用测试，再检查业务插件兼容。BlackFlow 快照插件由已定位的 `lubiao-analysis` 维护，联动流程见其中 `docs/data-pipeline/coordination.md`；宿主不引入游戏字段或固定业务仓库路径。
