本版增加按 SHA-256 检查并同步同名文件修订的能力。

- 订阅可开启“按云端修订记录校验并更新同名文件，旧文件留档”。本地内容与云端最新修订的 SHA-256 相同则跳过，不同则下载并完整校验，再保留旧文件、替换本地文件。
- 没有修订记录的文件继续按原方式追加下载。修订同步为可选功能，升级后需在对应订阅中开启。
- 原件保存在 `.sync-recycle/`，修订记录包含修改说明、前后 SHA-256 和文件路径。取消、下载损坏或下载期间本地文件被编辑时，不覆盖原文件；中断后可恢复处理。
- 维护上传支持超时退出、分片进度，以及核对已上传分片后续传。新内容完整回读校验后才替换云端原路径，修订记录最后提交。
- 兼容旧版下载器保存的压缩修订记录；未知协议、修订链分叉或已应用历史缺失时停止更新并报告问题。

提供 Windows x64、macOS Universal（Apple Silicon / Intel）、Linux x64 和 Linux ARM64 免安装运行包，各附 SHA-256 校验文件。

工具更新不会审核或批准历史数据的修改内容。历史包的修订仍需维护者审核并单独发布记录；升级工具本身不会发布待审修订。
