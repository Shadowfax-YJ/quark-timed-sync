修复已经校验过的修订仍在每轮重新下载记录、完整读取压缩包的问题。

- 记录和本地文件未变化时复用校验结果，程序重启后继续有效。新增修订只处理新增部分；云端历史缺失、同编号冲突和本地文件变化仍会被检查。
- 首次读取修订记录改为最多四条并行，并保存已完成进度。卡片和日志显示记录复用数、文件复用数及更新数。
- 增加“完整校验修订”按钮，可主动重新读取全部修订记录和对应文件。日常“立即检查”和定时检查默认使用增量校验。
- 旧版本升级后首次检查需要建立缓存，之后复用。无需重新配置订阅或安装其他运行环境。
- 包含修订发布回执丢失后避免重复上传记录，以及 Windows 短暂文件占用时重试原子状态写入的修复。

提供 Windows x64、macOS Universal（Apple Silicon / Intel）、Linux x64 和 Linux ARM64 便携包及 SHA-256 校验文件。发布流程使用 GitHub Actions 的自动测试、打包运行检查和同一 Universal 包的双架构检查，确认全部通过后发布构建附件。
