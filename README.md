# 夸克网盘定时同步

一个用于夸克网盘的开源桌面工具：定时检查网盘文件夹或分享链接，把新增文件自动下载到本地，保持原有目录结构。

支持 Windows x64 和 Apple 芯片 Mac。提供免安装便携包，内置运行环境、OpenList 和 rclone，无需自行部署服务。

## 下载与开始使用

在 [Releases](https://github.com/Shadowfax-YJ/quark-timed-sync/releases/latest) 下载适合自己系统的 ZIP，完整解压后打开 **夸克网盘定时同步**。

1. 使用手机夸克扫码登录自己的账号。
2. 添加订阅：浏览自己的网盘目录，或粘贴分享链接并选择其中的目录。
3. 选择本地目标文件夹，设置检查间隔，开始订阅。

默认每 **60 分钟**检查一次，可调整为 5～1440 分钟。所选云端目录里面的内容会直接保存到本地目标目录。

例如，选择云端的 `archive` 文件夹，再选择本地的 `D:\Downloads\archive`。

## 下载规则

- 只下载本地尚未存在的文件，包括初次订阅时缺少的历史文件。
- 保持目录结构；同名文件无论大小或修改时间是否变化，都会跳过。
- 不覆盖、不删除本地文件，不生成旧版本。
- 重新进入已有子目录，发现后来添加的文件。
- 中途停止不会把未完成内容当作完整文件；下次检查会重试未完成的下载。

别人分享的内容会先转存到自己的网盘 `Archive 订阅/订阅-编号` 目录，再下载到本地，因此需要自己的夸克账号和足够的网盘空间。程序不会自动删除转存文件。属于当前账号的分享会直接读取原文件，不会重复转存。

本工具通过**轮询**检查更新，不依赖夸克服务端推送。它是非官方客户端，接口可用性及下载速度仍受夸克接口和账号权益影响。

## 托盘、通知与启动

- 关闭窗口后继续在 Windows 系统托盘或 Mac 菜单栏运行。
- “暂停全部”停止当前下载与后续自动检查，暂停状态会保留。
- “立即检查”可在暂停期间手动检查一次。
- “退出并停止下载”结束应用及内置组件；退出后没有独立任务继续检查。
- 下载完成时可发送系统通知。
- 登录电脑时自动启动默认关闭，可在界面中开启或关闭。

移动程序文件夹后，请重新设置开机启动。改变订阅来源或本地目录时，移除该订阅后重新添加即可；移除规则不会删除文件。

## 平台与数据

Windows 包面向 x64；Mac 包面向 Apple 芯片、macOS 12 或更新。macOS 构建和启动检查在 macOS 15 Apple Silicon 上完成，所有内置可执行组件的最低系统要求均检查为不高于 macOS 12；尚未在 macOS 12 实机验证。

Mac 包采用本地签名，尚未经过 Apple Developer ID 公证。若首次打开被拦截，请按照系统提示，在“隐私与安全性”中选择“仍要打开”。

“便携”表示免安装、无需外部运行依赖。配置保存在系统用户数据目录中，更名后沿用原有位置，以保留已有登录和订阅：

- Windows：`%APPDATA%\Archive Subscriptions`
- Mac：`~/Library/Application Support/Archive Subscriptions`

登录凭据由系统加密保存；内置网盘服务只监听 `127.0.0.1`，使用随机密码和端口。分发包不包含账号或个人订阅配置，每个人需登录自己的账号。

## 开发与构建

需要 Node.js 24。Mac 构建还需要 Go 1.26.2，以便从未修改的上游源码编译兼容 macOS 12 的 rclone。

```sh
npm ci
npm run vendor
npm test
npm start
```

生成当前平台的便携 ZIP：

```sh
npm run package
```

输出位于 `out/`，同时生成 SHA-256 校验文件。Mac 的签名和打包需在 Mac 上完成。

界面与内置组件检查：

```sh
npm run smoke
```

Windows 还可使用 `npm run smoke -- --test-startup`，验证真实系统启动项的开启、界面重载后状态读取和关闭。该测试使用临时身份和数据目录，并在结束时移除测试启动项。

GitHub Actions 会在 Windows 与 macOS Apple Silicon 上构建、运行测试并验证打包后的应用。

图标采用予愿安洁莉娜主题，应用与任务栏使用完整插画，托盘使用简化头像，Mac 菜单栏使用随系统明暗变化的单色版。设计来源和素材导出方法见 [图标说明](assets/branding/README.md)。执行 `npm run icons` 可重新导出图标，不会构建应用安装包。

## 验证范围

自动化测试覆盖新增文件扫描、已有内容保留、递归更新、分享转存分支、取消下载、路径检查、内置组件退出和长期运行后的连接刷新。

真实夸克目录及当前账号持有的分享已完成小文件下载验证，下载内容与本地原文件一致，再次检查会跳过该文件。跨账号分享转存已实现并通过模拟测试，尚未完成另一账号的全流程实测。
